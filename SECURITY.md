# Security policy

## Reporting a vulnerability

Please use GitHub's private vulnerability reporting from this repository's
**Security** tab. Include the affected version, reproduction steps, impact, and
any suggested mitigation. Please do not disclose an unpatched vulnerability in
a public issue.

VectorMojo has no backend and uploads no design files. A report is especially
helpful if it identifies a dependency or browser behavior that can transmit,
persist, or expose a user's local file unexpectedly.

## Supported versions

Security fixes target the current deployment and the latest revision of the
`main` branch.
